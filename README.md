# Порівняння ноутбуків

## Мета проєкту

Створення вебсторінки з таблицею порівняння ноутбуків,
використання семантичної HTML-розмітки, стилізація таблиці,
підключення локального шрифту та нормалізація стилів.

## Використані технології

- HTML5 — створення семантичної структури вебсторінки.
- CSS3 — оформлення та стилізація елементів.
- Normalize.css — нормалізація стандартних стилів браузерів.
- WOFF2 — локальний шрифт, підключений через @font-face.
- Git та GitHub — контроль версій і зберігання вихідного коду.
- GitHub Pages — публікація вебсторінки.

## Реалізовані можливості

- Центрований контентний контейнер з обмеженою шириною.
- Локальний шрифт із системним резервним шрифтом.
- Семантична структура таблиці з атрибутами scope.
- Об'єднання комірок з однаковими характеристиками.
- Межі та внутрішні відступи комірок.
- Чергування кольорів рядків таблиці.
- Оформлення таблиці за допомогою box-shadow.
- Нормалізація стандартних стилів браузерів.

## Перевірка результату

Сторінку фактично перевірено у браузерах Google Chrome
та Microsoft Edge.

Під час тестування перевірено:
- Завантаження локального WOFF2-шрифту.
- Застосування резервного системного шрифту.
- Обчислені стилі елементів у DevTools.
- Центрування контентного контейнера.
- Відображення меж, відступів та кольорів таблиці.
- Коректність відображення об'єднаних комірок.
- Відсутність небажаного горизонтального переповнення
  при зміні ширини вікна браузера.

## Результат тестування

Візуальних відмінностей між Google Chrome та Microsoft
Edge не виявлено. Локальний шрифт завантажується коректно,
а за його відсутності застосовується резервний системний
шрифт. Таблиця та контентний контейнер відображаються
стабільно в обох браузерах. Усі перевірки пройдено успішно.
